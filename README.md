# 自媒体工作台 · Creator Workbench

一个面向中文内容创作者的 Windows 桌面工具：把视频整理成抖音、哔哩哔哩、小红书和 X 的文案，再结合公开热点、历史内容与评论寻找下一条选题。

**这是可运行的早期源码版本，需要配置本地工具。** 仓库没有打包好的安装程序、模型文件或预登录账号。

## 能做什么

- **视频转文案**：导入本地视频，抽取画面、读取字幕或在本机识别语音，然后通过已登录的 Codex 整理摘要与四平台草稿。
- **小红书和 X 正文**：从视频已有内容提炼独立可读的发布文案；不确定信息单列，发布前可校对。
- **先选题，后写脚本**：手动点击生成3个选题，说明推荐依据；点击某一条“展开拍摄方案”才生成对应口播、镜头和准备材料。
- **热点与评论**：尝试读取抖音公开热榜、B站搜索热词和可用的公开评论；来源、获取时间、缺失情况会保留。
- **本地作品库**：记录发布链接、评论和指标，支持编辑、复制、导出、旧版本保留与备份。
- **保留时间，复制正文**：文字稿显示时间标记；“复制纯文字”和文字稿选区复制会去除行首时间标记。

选题方法采用 [cheat-on-content](https://github.com/XBuilderLAB/cheat-on-content) 的适用片段，并调整为工作台的“热点、历史去重、延续与探索”流程。当前没有经过个人数据校准的分数或播放量预测。

## 快速启动

当前桌面流程主要面向 **Windows 10/11**。需要 Git、Node.js 22 或更高版本，以及已安装并完成 ChatGPT 登录的 Codex。订阅是否可用、模型和额度以当前账号的真实响应为准；本项目不把 ChatGPT 订阅视为 OpenAI API 余额。

```powershell
git clone https://github.com/F123f456789/-.git creator-workbench
cd creator-workbench
npm ci
npm start
```

应用会在项目目录内创建 `data/`、`cache/` 等文件夹，请将整个项目放在有足够存储空间的位置。需要桌面入口时，运行：

```powershell
npm run setup:shortcut
```

安装依赖后也可双击 `启动自媒体工作台.vbs`。第一次进入可先设置内容方向和视频时长，方向不确定时可以留空。点击“验证连接”会发起一次真实模型请求，占用当前账号的可用额度。

## 配置视频处理工具

视频处理需要 FFmpeg 和 FFprobe。自动语音识别另外需要带 `faster-whisper`、`ctranslate2` 的 Python 环境，以及已下载到本地的兼容语音模型目录。仓库不会自动下载模型。

复制 `runtime-config.example.json` 为 `runtime-config.json`，填入本机的实际文件路径；这个本地配置已被 Git 忽略。也可设置同名说明对应的环境变量：

| 环境变量 | 用途 |
| --- | --- |
| `WORKBENCH_FFMPEG` | FFmpeg 程序的完整路径 |
| `WORKBENCH_FFPROBE` | FFprobe 程序的完整路径 |
| `WORKBENCH_PYTHON` | 已安装语音识别依赖的 Python 程序路径 |
| `WORKBENCH_WHISPER_MODEL` | 本地 faster-whisper 模型文件夹 |
| `WORKBENCH_CODEX` | 可选：Codex 程序的完整路径 |
| `WORKBENCH_CONTENT_SKILL_DIR` | 可选：使用另一份完整 cheat-on-content 技能目录 |

未明确配置的 FFmpeg、FFprobe 和 Python 可从系统 `PATH` 查找。与视频同名、同目录的 `.srt`、`.vtt`、`.txt` 字幕会优先使用。已有字幕或视频没有音轨时，无需加载语音识别模型。

默认内容方法参考已随项目提供，见 `vendor/cheat-on-content/`，不要求开发者电脑预先安装全局 skill。这个目录是应用所需参考文件的子集，不是完整技能安装包。

## 日常操作

1. 导入视频，校对识别出的文字；或使用“抖音链接转文案”尝试读取完整视频。
2. 在四个平台页签中查看、编辑和复制文案。小红书是标题与正文，X是一条中文短帖。
3. 自行发布后，把作品链接关联到同一条作品记录。
4. 读取可用评论和指标，或导入自己从平台导出的评论文件。
5. 点击“生成选题”，选择感兴趣的一条，再点“展开拍摄方案”。

“生成新版本”会保留旧稿及编辑记录。默认手动运行；如果自行开启定时，也只有电脑开机且应用运行时才会检查，生成的默认仍然只有选题。

## 当前边界

- 抖音链接读取依赖页面提供完整且可读取的 HTTPS 音画文件。登录、验证、分段流或平台改版可能阻止读取；此时可补入本地原视频。不能保证任意链接都成功。
- B站公开数据受平台响应影响；抖音和小红书窗口只读取已加载、能够识别的内容。X回复目前需要手动导入，避免混入推荐帖。
- 平台返回的公开评论样本不代表全部观众。热榜时间是获取或榜单更新时间，不等于事件发生时间，也不构成事实核验。
- 视频画面是抽样观察，语音识别可能出错。AI结果需要人工校对；本工具不保证流量，不代替本人发布内容。
- 本地生成、编辑和隔离测试通过，并不等于每个平台的登录采集都已稳定验证。

## 数据与连接

作品、视频、评论和文案保存在本机 `data/`。平台窗口的登录状态也属于本地应用数据。生成时，提供的文字及抽取画面会发送给当前 Codex 连接的模型；应用不会把全部原视频上传给模型。热点和平台数据读取会访问相应网站。

应用调用已有的 ChatGPT 登录，不提供付费 API 回退，不自动购买额度。需要本人完成登录或平台验证。备份不包含平台窗口的登录信息。

**请勿提交 `data/`、`cache/`、`verification/`、导出、备份、账号信息、密钥或本地配置。** `.gitignore` 已排除这些路径；分享日志前仍应检查内容。仓库中只有程序、合成测试和方法参考，没有个人运营资料。

## 开发与测试

```powershell
npm ci
npm test
```

常规测试不访问真实社交平台或模型。媒体检查使用 FFmpeg 在本地生成短色块视频；未安装 FFmpeg/FFprobe 时会明确跳过相关媒体检查，其余测试继续执行。

需要单独验证真实模型连接时运行 `npm run verify:ai`。它会使用当前账号额度，并将本地回执写入已忽略的 `verification/`。

主要目录：`src/` 为桌面和业务逻辑，`ui/` 为界面，`tests/` 为隔离检查，`scripts/` 为启动与语音识别辅助程序，`内容方法/` 为工作台方法约定。
